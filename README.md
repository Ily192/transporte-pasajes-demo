# Transportes Demo · Sistema de pasajes, encomiendas y giros

Demo navegable de un sistema de gestión y venta de pasajes para una empresa de transporte. **Todos los datos son ficticios** (rutas, horarios, precios, pasajeros) y lo que se registra se guarda solo en el navegador.

**Ver demo:** https://ily192.github.io/transporte-pasajes-demo/

- **Web del pasajero:** búsqueda de viajes, selección de asiento por tipo de vehículo (automóvil, camioneta, minivan, minibús), reserva temporal del asiento, pago con Yape o tarjeta (simulado), boleto con QR y comprobante electrónico.
- **Agencia:** venta en counter con boleta o factura, encomiendas con código de seguimiento y entrega con DNI, giros con clave de cobro, caja del día.
- **Gerencia:** ventas por día, ruta y canal, ocupación de salidas, manifiesto de pasajeros, flota y tarifas, exportación a CSV.
- **WhatsApp (simulado):** horarios, precios, seguimiento de encomiendas y derivación a una persona.
